## 反思

我在這站對於環境的構思想了很久，起初我想從上周的初始世界觀去修正，但我發現到後來變成我自己也很難解釋為什麼想要這樣，於是我從頭開始。我想到先前人類文明還未迅速發展時，整個地球應該要是綠意盎然的，於是我改成森林樣，然後我請agy幫我多查相關research，發現這樣的環境比起一開始的海底世界既有更好的現實生活研究，也更好解釋。不過我一直不太確定環境的具體程度應該要到哪裡，所以我又跟agy相互討論了很久，到最後終於共同討論出一個我滿意的世界觀。但是因為這是一個全新的世界觀，可能報告後還是會有很多要修正的地方，就等課堂報告老師看過後再去修正。
