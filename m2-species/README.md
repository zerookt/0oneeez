## 反思
這次的作業我卡在改變終端機ai很久，然後agy也不知道為甚麼一直說額度用完了。所以我把我的生物雛型貼給claude，請他幫我根據這些內容生成一個世界。一開始我以為會是我所想像的很夢幻的樣子，但呈現出來的好像沒有想像中夢幻，跟claude談了幾次還是如此，可能之後要再給ai喂更明確的世界觀想像，不過這個誠品還蠻可愛有趣的，但還是希望之後可以做得更好。
