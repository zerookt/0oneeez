## 二、M2 解掉的效能問題（簡報／反思可用）

- **症狀**：畫面一直卡在 30fps，不管怎麼改參數都一樣
- **關鍵數字**：左上角顯示 `30 fps ・ 運算 16ms` → 一秒 60 幀的預算只有 16.6ms
- **原因**：瓶頸是**繪製呼叫次數**，不是顯示卡畫不動
  （p5 每呼叫一次 `box()`／`sphere()` 大約花 15~20 微秒，800 多次就吃掉 16ms）
- **解法**：用 p5 內建的 `buildGeometry()`，在 `setup()` 把「不會動的裝飾」合併成一大塊幾何

| 項目 | 之前 | 之後 |
|---|---|---|
| 遠樹板根鰭 | 220 次 | **1 次** |
| 主體樹板根 | 224 次 | **1 次** |
| 苔丘 | 28 次 | **1 次** |
| 磨菇 | 36 次 | **1 次** |
| 全部 | 約 830 次 | **約 260 次** |

- 一個踩到的細節：畫合併幾何**之前**要先 `texture(whiteTex)`（自己做一張白色 1×1 貼圖），
  把殘留的樹皮／地面貼圖蓋掉，不然合併幾何的顏色會被貼圖影響
- 這段可以講成「**用數字找原因，而不是亂猜**」的過程

## 五、M3 新增：日夜循環（2026/10/22）

> 這一段是 M3 站做的世界改動，程式在 `m3-creature/`。`m2-species/` 沒有動。

### 怎麼用
| 操作 | 功能 |
|---|---|
| 等 90 秒 | 自動走完一輪（白天約 40 秒 → 黃昏 9 秒 → 夜晚 36 秒 → 黎明 4.5 秒） |
| N | 自動 → 鎖定白天 → 鎖定夜晚 → 自動（四段循環） |
| 網址加 `?night` | 一開場就是夜晚 |
| 網址加 `?dusk` | 一開場就停在黃昏 |
| 網址加 `?shot` | 隱藏所有介面，用來截乾淨的圖 |
| 左上角 | `☀ 白天`／`🌗 黃昏`／`☾ 夜晚`＋fps |

### 關鍵參數（`night` 0＝白天、0.5＝黃昏、1＝深夜；顏色用三段式 `mixNight()` 插值）
- 環境光：白天 `95,120,110` → 黃昏 `72,64,74` → 夜晚 `18,26,48`
- 主光：白天暖陽 `255,235,190` → 黃昏斜射橘光 `255,172,112` → 夜晚月光 `150,175,225`，方向也換到另一側
- 天空 `background`：`22,44,40` → `52,36,44` → `7,11,22`
- 太陽光斑與光束：alpha 乘 `(1-night)`，黃昏就淡掉
- 月亮：世界座標固定在右上方的天空（`y=-430`、離中心約 690），非常慢地漂移；本體用 `noLights()` 畫，否則會被昏暗的環境光吃掉
- 月光在溪面：沿水流方向的 3 條加法混色反光帶，`180,212,255`、alpha 約 10·night

### 人工海玻璃卵石（M1 第 4 點）
- 14 顆，半徑 3~8，壓扁成 `scale(1,0.38,1)`，沿溪床放，中心 `y=-0.8`（半埋在水裡）
- 四種顏色：青綠 `140,205,190`／琥珀 `220,190,140`／乳白 `225,235,230`／灰藍 `170,195,220`
- 夜間的「反射」是假的但看起來會閃：
  `glint = night × max(0, 月亮方向 · 視線方向)^6`
  → 月亮在你背後、你正看著石頭時最亮，轉個角度就暗掉

### 發光體夜間加成
| 東西 | 變化 |
|---|---|
| 真菌綠光光暈 | alpha `16×f.hl` → 夜間最高 50 |
| 蜜露滴 | 半徑 +1.6、外加 11px 的橘色光暈 |
| 孢子 | 亮度 150 → 245 |
| 皮皮核心 | `P.glow` 夜間下限 0.5 → 0.72 |
| 皮皮身體 | 上緣一圈淡冷白月光（alpha 26·night），白天不執行 |

### 設計取捨（反思可以用）
1. **夜晚只壓到約 15% 亮度**：M1 寫的 0.001 Lux 是真的物理，但照做會全黑看不到東西；我選擇「剪影看得出來、只剩發光體有顏色」。
2. **15% 不是憑感覺**：先讓畫面暗到樹幹還看得出輪廓，再檢查皮皮是否仍是畫面最亮的一點。
3. **嘗試過但放棄的做法**：讓整隻皮皮疊一層暖色加法光 → 臉被光洗掉、變成一團白，所以拿掉，改成讓核心的光從胸口透出來。
4. **月亮的光暈不能用貼圖加 ADD**：p5 在加法混色下會忽略貼圖的 alpha，整片變成白色方塊；最後用 24 層同心圓疊出來。

### 能量系統（2026/10/23 追加）
> 核心的亮度＝牠的能量。能量越低越不亮、飛得越慢；能量靠吃真菌與蜜露補充。

| 項目 | 數值 |
|---|---|
| 開場能量 | 0.5（`?en=0.1` 可以指定，示範用） |
| 消耗 | 每幀 `0.00005 + 速度×0.000012` → 一直飛約 50 秒見底，停著約 3 分鐘 |
| 吃真菌（靠近吸） | 每幀 +0.0025 |
| 喝蜜露 | 每幀 +0.004 |
| 點真菌餵食 | 一次 +0.12，真菌會縮小、噴光點飛向她 |
| 發光 | `glow = 0.18 + 0.64×能量`（能量 0.5 時剛好是原本 M2 的亮度） |
| 沒力 | 能量 <50% 開始變慢，最低只剩 40% 速度；<30% 眼睛半閉；<25% 光會一閃一閃 |
| 見底（<12%） | 沒有操控時會自己慢慢飄去最近的菌叢吃 |

### 互動（點擊）
| 動作 | 反應 |
|---|---|
| 點牠一下 | 彈跳＋核心閃光＋瞇眼＋噴彩色光點 |
| **連點牠三下** | 打滾一圈＋大量金色光點＋能量 +0.04 |
| **點真菌** | 餵食：真菌縮小、光點飛向她、能量 +0.12 |
| 點空白 | 地震 0.7 秒 |

### 能量系統的設計取捨（反思可用）
1. **能量 0.5 對應原本亮度**：這樣「加了一個系統」但沒有把 M2 定案的外觀改掉。
2. **低能量不要只做「暗」**：同時讓眼睛半閉、漂浮幅度變小、速度下降，才看得出「沒力」而不是「燈壞了」。
3. **光一閃一閃只在 <25%**：如果全程閃會很吵，只在快沒電時閃才有意義。
4. **她自己會去覓食**：這是最能表達「活的」的一條——不用玩家操作，她也會為了活著而移動。

## 七、M3 改進：天球日夜、生物天性、能量冷寂復甦與人造殘留物（2026/11/05）

### 1. 自然化天球日夜系統（改善原本的突兀感）
- **真天球軌跡**：太陽與月亮呈 180 度穹頂對稱升降。中午時太陽位於天頂直射，日落時太陽沉入西方樹梢，月亮由東方緩緩升起。
- **大氣散射與微光時間**：
  - 白天約 36 秒：溫柔的樹冠漫射光與搖曳金色光斑。
  - 黃昏暮光約 12.6 秒：斜射低角夕陽金光，天空過渡為紫橘色暮霞。
  - 深夜約 30.6 秒：高空冷銀月光、溪流月光波帶與發光體夜間加成。
  - 破曉晨曦約 10.8 秒：東方微曦桃金色晨光，從容破曉，不再是突兀亮起。

### 2. 晶靈樹醫 Pippa 的核心冷寂與漸進復甦
- **能量見底（<= 5%）的「冷寂休眠」**：
  - 核心自發光完全歸零，晶體變為無光的冷灰石英核。
  - 四層橘色暖光暈完全消散收縮。
  - 尾部四條觸鬚失去浮力，受重力自然向下垂墜（垂墜幅度達 24px）。
  - 眼睛閉合為疲憊細縫，上下呼吸浮動極為緩慢沉重。
- **補充能量的「漸進復甦」**：
  - 吃到養分後，核心不會瞬間暴亮，而是由中心先亮起一顆如微弱火星的赤紅餘燼點。
  - 隨能量提升，光芒平滑升溫為琥珀金光；四圈光暈依能量門檻（>8%、>25%、>45%、>70%）由內而外依序綻放。
  - 觸鬚重新恢復靈動飄浮，眼睛張開展現活力。

### 3. 物種天性與互動
- **樹醫巡診治癒（點擊真菌）**：Pippa 飛近病變真菌進行淨化，散發翠綠光環波紋與能量光塵，修復樹皮環境並吸收甘露。
- **母樹依戀與棲息（閒置天性）**：玩家放開控制超過 5 秒，Pippa 不會定在半空，而是自然緩緩漂回古樹板根空腔依偎休憩。
- **地震驚嚇防禦（點擊空白地面）**：地面震動時，Pippa 受到驚嚇，迅速抱頭向內縮成一顆緊湊的圓滾滾「珍珠防禦球」，平息後才謹慎舒展。

### 4. 人造殘留物（Technofossils，呼應 M1 世界觀）
- **溪床海玻璃**：36 顆多樣化殘留物，包含圓潤扁平海玻璃、厚底凹槽瓶底圓片（翠綠、啤酒琥珀、鈷藍、乳白）與陶瓷碎片。
- **板根吞沒的金屬遺跡**：巨樹基底有一圈被樹根吞沒、覆滿苔蘚的古老惰性鈦金屬環（五千年不朽的人類遺跡）。

### 5. 生動表情系統（眼神靈魂高光、視線微動與多種情境表情）
- **靈魂眼部高光（Catchlights）**：眼球加上主高光（右上角水潤亮點）與副高光（左下角晶透微光），不再是死板黑珠；治癒時高光更映照出翠綠微光。
- **視線追蹤微動（Gaze Shift）**：飛行與移動時，眼珠與高光會依飛行速度方向（`lookX, lookY`）好奇張望轉動。
- **情境五段表情**：
  - **開心笑眼（`^ ^`）**：點擊撫摸或翻滾時，眼睛彎成上揚月牙弧、腮紅放大發亮、嘴巴微開笑開懷。
  - **驚嚇防禦（`> <`）**：地震時雙眼緊閉緊縮、腮紅變淡、小嘴嚇得張成圓形「O」型喘息。
  - **巡診治癒中**：眼神倒映翡翠光澤、嘴巴呈現專注吸吮甘露的一開一合律動。
  - **自然眨眼呼吸**：偶爾觸發靈動雙眨眼，小嘴隨呼吸微嘟起伏。
  - **能量耗盡**：高光完全熄滅、眼睛閉合為下垂細線、嘴角無精打采微癟。

## 八、M3 族群生態先導與遺跡強化（2026/11/05 追加）

### 1. 強化海玻璃與金屬遺跡辨識度
- **大型地標酒瓶底（Landmark Glass）**：
  - 溪畔加入 3 座大型厚底凹槽瓶底殘件（半徑 22~26，翠綠、琥珀、鈷藍），帶有明顯工業凹槽倒角。
  - 白天帶有透光折射微暈（Caustic halo），夜間具備強烈月光鏡面高光（Specular glint）。
- **古老大型鈦合金科研環遺跡（Ancient Titanium Tech-Relic）**：
  - 尺寸大幅放大至直徑 110（`torus(52, 11)`），半埋於古樹板根空腔基座。
  - 具備工業安裝座螺栓幾何、樹幹裂縫延伸出的 3 根古老金屬鋼纜束，表面覆蓋爬行苔蘚，具備強烈金屬光澤對比。

### 2. 四隻野生獨立 NPC 樹醫（生態棲位與接近觸發天性）
- **NPC 棲位分布與自然生態**：不跟隨玩家成群移動，而是各自生活在特定生態棲位中，只有 Pippa 靠近時才會觸發獨特的野生互動本性：
  - **暮暮（Drowsy）**：隱居在背陰板根樹洞深處（`x:-135, y:-65, z:-150`），平時縮成一團打瞌睡；Pippa 接近時甦醒、核心升溫並伸懶腰彈跳，噴出暖金光塵打招呼。
  - **瀾瀾（Dew）**：在清溪淺灘低飛（`x:cx(240), y:-25, z:240`），平時在水面點水激起漣漪；Pippa 接近時喜悅盤旋，向 Pippa 輸送純淨水氣甘露（補充水分與能量）。
  - **苗苗（Sprout）**：在樹幹高處真菌旁工作（`y:-190`），平時專注噴微光養護真菌；Pippa 接近時興奮點頭致敬，Pippa 治癒真菌時形成共鳴光流。
  - **幽幽（Glint）**：在大型鈦金屬環遺跡旁徘徊（`x:R+52, y:-24, z:40`）；Pippa 接近時害羞躲在金屬環與樹根背後偷看，停留會俏皮探頭吐出金色氣泡捉迷藏。
- **全體地震防禦本性**：發生地震時，所有 NPC 會在自己的棲息地同步收縮抱頭成珍珠防禦球。
